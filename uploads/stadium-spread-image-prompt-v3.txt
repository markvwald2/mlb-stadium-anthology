Use this prompt structure when the user asks for the image-generation prompt instead of direct image generation.

==================================================

Create a finished premium large-format landscape two-page coffee-table book spread for an MLB stadium anthology.

Physical size, mandatory: 25.50 inches wide x 10.88 inches tall.

Target print/export resolution: 7650 pixels wide x 3264 pixels tall, 300 DPI, full landscape spread.

Blurb production basis: Large Landscape Photo Book 13 x 11 in. Single page with bleed is 12.75 x 10.88 in; trimmed page is 12.50 x 10.63 in. Bleed art must extend at least 0.125 in beyond final trim, and critical text or image details must stay at least 0.25 in inside final trim.

The size and aspect ratio are non-negotiable. Preserve the exact 25.50:10.88 landscape aspect ratio. Do not generate a square image, portrait image, cropped spread, single-page layout, or alternate-aspect composition.

If exact 7650 x 3264 px output cannot be guaranteed by the image tool, render the closest supported pixel size that preserves the exact 25.50:10.88 aspect ratio. Do not refuse solely because exact pixel dimensions are unavailable. Treat 7650 x 3264 px as the print/export target.

This is a finished print-ready editorial spread, not a mockup. Do not include a book cover, page curl, binding hardware, table surface, hands, outside shadows, or surrounding environment.

Use a precise, dense, archival, architectural editorial design system combining vintage baseball programs, architectural monographs, museum-quality infographics, and modern magazine layouts. Avoid sports-poster aesthetics, ESPN-style graphics, sentimental nostalgia, fantasy lighting, souvenir collage composition, or loose mockup styling.

Use no data or information that is not contained in the local uploaded data files. Never use web browsing, web search, model memory, general baseball knowledge, or plausible filler for stadium facts, visit facts, game facts, metrics, dates, statistics, captions, labels, editorial claims, or explanatory copy. Do not invent metrics, categories, ratings, comparisons, rankings, or editorial interpretations.

Use `stadium-field-map.md` as the fixed assignment of CSV fields to the Stadium Section and Visit Section.

Photos may be externally sourced or generated, but they may not introduce visible factual claims. Do not label anything from a photo unless the label comes from the local data files.

The spread is a physical two-page layout:

* Left page: x = 0 to 12.75 inches.
* Right page: x = 12.75 to 25.50 inches.
* Exact center split: x = 12.75 inches.
* Show a subtle visible vertical page split at x = 12.75 inches as a flat hairline or clean page division only.

* No readable text, data tables, score lines, labels, section headings, faces, important stadium details, or key image subjects may appear inside the gutter zone.
* The gutter may contain only background continuation, quiet texture, or nonessential abstract design elements.
* Do not add a binding shadow, gutter shadow, fold shadow, dark center gradient, or simulated book crease.
* Do not place any module across the gutter.
* Every major module must belong clearly to either the left page or the right page.

Each visible data value may appear only once on the spread. If the same value could appear in multiple places, choose the strongest single module and omit the duplicate everywhere else. Do not repeat values between the metadata ribbon, facts table, construction data values, field module, featured game module, weather module, or Stadium Context callouts. For example, do not show `Open Air` twice, and do not repeat `years_active` in both the ribbon and construction data.

Color fields count as used when they are applied as visual accent colors; their color names do not need to be printed as text unless the layout explicitly needs a color legend.

All structured fields must follow the fixed Stadium/Visit assignment in `stadium-field-map.md`.
