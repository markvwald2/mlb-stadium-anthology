# Claude Design Sprint Brief

## Purpose

Explore a Claude-influenced design direction for the MLB stadium book without replacing the existing production system.

Use this as a focused visual sprint: generate a small set of alternate spreads, compare them against the current book rules, and decide which design moves are worth folding back into the main template.

## Design Hypothesis

Claude-style design may help this project by making dense stadium information feel calmer, more intentional, and more editorial.

The useful qualities to test:

- Restrained hierarchy
- Clear grouping of dense data
- Generous but controlled whitespace
- Museum-label precision
- Editorial confidence
- Quiet typographic polish
- Data modules that feel designed, not merely placed

The risk to avoid:

- Too much modern SaaS/product-dashboard language
- Too little vintage baseball program texture
- Layouts that feel generic, smooth, or placeless
- Decorative design that weakens the stadium-first premise

## Non-Negotiables

Keep all existing project constraints:

- Full spread size: 25.50 in x 10.88 in
- Target export: 7650 x 3264 px at 300 DPI
- Left page: full-bleed stadium hero image with title only; keep the title compact so the photo remains dominant
- Right page: exactly two visually distinct sections, Stadium Section and Visit Section
- No critical content in the gutter zone
- Local data only
- Every populated structured value appears exactly once
- Stadium facts stay in the Stadium Section
- Visit and game facts stay in the Visit Section
- Stadium Context appears in full when used
- No invented labels, ratings, claims, slogans, or filler facts

## Recommended Test Set

Create three to five spread concepts from this list:

- Fenway Park: jewel-box, active, dense history, two featured games
- Tiger Stadium: demolished jewel-box, urban enclosure, strong archival feel
- Riverfront Stadium: multipurpose concrete era, circular geometry, demolished
- Mile High Stadium: interim MLB expansion venue, unusual capacity and site story
- PNC Park: modern retro-classic, riverfront, strong architectural imagery
- Coors Field: local/personal anchor, retro warehouse district, first Rockies permanent park

This set tests whether the design system can handle different eras, different amounts of data, active versus demolished parks, and single versus multi-game visit blocks.

## Visual Direction To Test

Use the existing book palette and typography intent as the base:

- Cream, navy, red, black, and muted team accents
- Serif headline language
- Sans-serif or tabular typography for data
- Strong grid
- Archival print texture
- Vintage program influence

Apply Claude-style restraint through:

- Fewer, stronger modules
- Cleaner vertical rhythm
- Small-caps labels
- Thin rules and precise alignment
- Calm sectioning instead of heavy boxes
- Dense information presented as deliberate editorial furniture
- More meaningful contrast between stadium material and visit material

Avoid:

- Dashboard cards
- Rounded app UI panels
- Neon sports graphics
- Oversized decorative badges
- Souvenir collage
- Faux scrapbook tape, tickets, stamps, or handwritten notes
- Modern gradient-heavy layouts

## Copy-Paste Prompt Addendum

Use this addendum with the existing `stadium-spread-template-v3.txt` and `stadium-spread-image-prompt-v3.txt` instructions.

```
For this concept, explore a restrained Claude-influenced editorial design direction while preserving all existing MLB Stadium Book requirements.

The spread should feel like a premium architectural monograph crossed with a vintage baseball program: calm, precise, information-rich, and print-aware. Use strong hierarchy, dense but disciplined whitespace, exact alignment, thin rules, small-caps labels, and clear module grouping. Make the right page feel fully and intentionally composed rather than sparse or busy.

Do not make the design feel like a web app, SaaS dashboard, sports broadcast graphic, souvenir collage, or generic coffee-table mockup. Avoid rounded app cards, glossy badges, decorative fake tickets, heavy gradients, and invented infographics.

Keep the left page as a full-bleed stadium hero with only a compact stadium title block. Style the title typography to echo the stadium's architecture, era, materials, site, or signage character rather than generic sports-poster lettering. Keep the right page divided into exactly two visually distinct sections: Stadium Section and Visit Section. Every populated local data value must appear exactly once, and no values may be invented, inferred, repeated, abbreviated, or moved across the Stadium/Visit boundary.

Use Claude-style restraint only as a design sensibility: cleaner hierarchy, calmer density, better typographic rhythm, and more intentional editorial grouping.
```

## Review Checklist

Score each concept from 1 to 5:

- Stadium-first visual impact
- Right-page readability
- Data completeness
- No duplicate or invented values
- Gutter safety
- Stadium Section and Visit Section separation
- Vintage baseball texture
- Architectural/editorial sophistication
- Repeat-viewing quality
- Fit with the rest of the book

Best outcome:

- Keep the original production template as the factual and structural authority.
- Borrow successful visual moves from the Claude-style experiment into the next template revision.
- Reject anything that looks polished but weakens the archival baseball-book identity.
