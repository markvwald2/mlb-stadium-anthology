Page spec & export steps

Interior page spec (Blurb Large Landscape, Hardcover ImageWrap): page 12.625 × 10.875 in (909 × 783 pt) · trim 12.5 × 10.625 in · bleed 0.125 in top/bottom/outside, none on the binding edge · safe 0.25 in outside/top/bottom, 0.5 in binding. The guides links draw these new trim / bleed / safe lines on screen — anything critical outside the dashed safe box is unsafe to print.

  1. Click a spread’s Left / Right button to open its print tab (works on click in Safari; in Chrome, pop this sheet out first or ask me to open it).
  2. In the print tab: Cmd/Ctrl+P → Save as PDF → Margins: None → Save. Backgrounds print automatically.
  3. Save each as <Stadium> - Left.pdf / - Right.pdf so the book assembles in order.

Each cell's guides link previews trim / bleed / safe overlays on screen (they auto-hide when printing). Type, rules, and diagrams export as true vector; only the dropped-in photos rasterize. Don't use the artboard ⋯ → "Download PNG" — that's raster, not press-ready.
